# nginx


### Test nginx config (foreground)
```bash
sudo nginx -t
```

### Reload config

```bash
sudo nginx -s reload
```

### Output config
```bash
sudo nginx -T
```

### Grep for duplicate server names
```bash
root@banana:/etc/nginx/sites-enabled# sudo nginx -T | grep -i "banana\.org"
2026/09/07 22:12:55 [warn] 39642#39642: conflicting server name "banana.org" on 0.0.0.0:80, ignored
2026/09/07 22:12:55 [warn] 39642#39642: conflicting server name "banana.org" on [::]:80, ignored
```

## View live traffic (Access Log)
```bash
tail -f /var/log/nginx/access.log
```

## View recent errors (Error Log)
```bash
tail -f /var/log/nginx/error.log
```

## View systemd log
```bash
journalctl -u nginx
```

### Config syntax: Exact match
- The syntax for an exact match is `= /`
- E.g. if you want to redirect the root directory to some other path
```bash
	location = / {
		return 301 /banana/;
	}
```
